# 微信发布状态问题 - 完整解决方案

## 问题总结

**现象**:
1. ❌ 发布成功后仍显示"未发布"
2. ❌ 时间显示不正确

**原因**:
- 微信发布是异步的，提交后状态为 `PENDING`
- 需要等待微信审核通过后状态才变为 `SUCCESS`
- 原系统没有自动更新机制

## 已实现的解决方案

### ✅ 自动更新机制

**触发时机**: 每次查询发布日志时

**更新逻辑**:
1. 检测到状态为 `PENDING` 的微信发布记录
2. 自动调用微信 API 查询最新状态
3. 更新数据库状态和时间
4. 返回最新结果给前端

### 使用方法

#### 方法 1：刷新页面（推荐）
1. 发布文章到微信后，等待 5-10 秒
2. **刷新浏览器页面**（F5 或 Ctrl+R）
3. 发布状态会自动更新为"已发布"

#### 方法 2：重新打开文章
1. 发布后关闭文章编辑页
2. 等待 5-10 秒
3. 重新打开该文章
4. 状态自动更新

## 时间显示说明

### 发布时间字段

- **提交时间**: 用户点击发布的时间（初始值）
- **实际发布时间**: 微信审核通过并发布的时间（更新后的值）

### 时间更新逻辑

```python
# 发布时
publish_log.published_at = datetime.utcnow()  # 提交时间
publish_log.status = PublishStatus.PENDING

# 状态更新时
if wechat_status == SUCCESS:
    publish_log.published_at = datetime.utcnow()  # 更新为实际发布时间
    publish_log.status = PublishStatus.SUCCESS
```

### 时区处理

- **后端存储**: UTC 时间
- **前端显示**: 自动转换为本地时间

## 常见问题

### Q1: 刷新后还是显示"未发布"？

**可能原因**:
1. 微信审核还未完成（继续等待）
2. 审核失败（会显示失败原因）
3. 网络问题导致状态查询失败

**解决方法**:
- 再等待 10-20 秒后刷新
- 检查浏览器控制台是否有错误
- 查看后端日志

### Q2: 时间显示不是发布时间？

**正常情况**:
- 未发布状态：显示"最近尝试"时间（提交时间）
- 已发布状态：显示"发布时间"（实际发布时间）

**如果时间明显错误**:
- 可能是时区问题
- 检查系统时间是否正确

### Q3: 需要手动刷新太麻烦？

**未来优化方向**:
1. 前端添加自动刷新（发布后 10 秒自动刷新一次）
2. 添加"刷新状态"按钮
3. 使用 WebSocket 实时推送状态更新

## 故障排查

### 1. 状态一直不更新

**检查后端日志**:
```bash
tail -f backend/logs/app.log
```

**查找关键词**:
```
Auto-updated PublishLog
Failed to update wechat status
```

### 2. 查询微信状态失败

**可能原因**:
- 微信 API 超时
- Token 无效
- publish_id 不存在

**解决方法**:
- 检查微信配置
- 验证 publish_id

### 3. 数据库未更新

**检查数据库**:
```sql
SELECT id, status, published_at, remote_id 
FROM publish_logs 
WHERE status = 'pending' 
ORDER BY published_at DESC 
LIMIT 5;
```

**手动更新**:
```bash
python -m app.scripts.update_wechat_status
```
